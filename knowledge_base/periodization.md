# Periodization — Structured Training Blocks

## Block Periodization Model (Issurin, 2010)
Training is organized in 3–6 week blocks, each with a specific goal:

### 1. Accumulation Block (3–4 weeks)
- Goal: build aerobic base, increase volume
- Intensity: 85–90% Z1-Z2, 10–15% Z3-Z4
- Volume: progressively increasing
- CTL rise: +3 to +6 per week
- Primary adaptations: mitochondrial density, capillary density, fat oxidation

### 2. Transmutation Block (2–3 weeks)
- Goal: convert base fitness to race-specific fitness
- Intensity: 70% Z1-Z2, 20% Z4, 10% Z5
- Volume: same or slightly reduced
- Key sessions: threshold intervals, tempo runs
- CTL rise: +2 to +4 per week

### 3. Realization Block / Taper (1–2 weeks)
- Goal: peak performance for race or time trial
- Volume: drop 40–60% from peak
- Intensity: maintain — short quality sessions, full rest otherwise
- TSB target on race day: 0 to +10 (fresh but fit)

## Annual Periodization (for 10K–Half Marathon focus)
- October–December: Base/Accumulation (high Z2 volume)
- January–March: Build/Transmutation (add threshold work)
- April–May: Race Phase (tune-ups, taper, race)
- June–August: Recovery + Base rebuild (post-race)

## 3:1 Weekly Structure
- 3 weeks progressive loading → 1 week deload
- Week 1: base volume
- Week 2: +10% volume
- Week 3: +10% volume  
- Week 4: -30% volume (deload)

## Long Run Guidelines
- Max long run: 25–30% of weekly total volume
- Never increase long run distance > 2 km per week
- Include 1 long run per week (for half marathon base building)
- Pace: Z2 (conversational), not Z3

## Peak Phase Tapering
- Begin taper 10–14 days before goal race
- Week -2: reduce volume 30%, maintain intensity
- Week -1: reduce volume 50%, 2–3 short quality sessions
- Race week: mostly easy, 2 short strides, 2 rest days

## Warning: Common Mistakes
- "Too much too soon" — ACWR > 1.5 after a return from rest
- Skipping deload weeks — chronic fatigue accumulation
- Racing in training — running threshold pace on supposed easy days
- No base — jumping to intervals without sufficient Z2 base
